# SIM-TKA Matematika Interaktif
> Platform Asesmen Mandiri & Simulasi Ujian Tes Kemampuan Akademik (TKA) Matematika SMA/SMK Berbasis Blueprint Pusmendik, HOTS Reasoning, dan Strict SVG Engineering.

---

## 🌟 Ikhtisar Aplikasi

**SIM-TKA Matematika Interaktif** dirancang dan dibangun dengan standar **Senior Frontend Engineer** dan **Educational Technology Specialist**. Aplikasi ini merealisasikan dokumen blueprint asesmen TKA Matematika ke dalam bentuk web interaktif modern dengan pendekatan **mobile-first & desktop-optimized**, rendering notasi ilmiah presisi tinggi via **KaTeX**, serta ilustrasi teknis berbasis **Native SVG Vector**.

### 🎯 Prinsip Transformasi Konten & Strict Non-Spoiler SVG Engineering
Sesuai arahan evaluasi pedagogis tingkat lanjut:
* **Presisi Matematis 1:1**: Mempertahankan esensi logika, tingkat kognitif (LOTS & HOTS), dan metode penyelesaian (SPLDV, SPLTV, SPtLDV, deret geometri bertingkat, optimasi fungsi objektif program linear, perbandingan trigonometri sudut tumpul, kombinatorika kode unik, dsb.).

## 📚 Cakupan 7 Modul Materi Terstruktur

1. **Aljabar & Sistem Persamaan/Pertidaksamaan**
   - SPLDV pengadaan komponen mikrokontroler & sensor ultrasonik.
   - SPtLDV penentuan daerah penyelesaian $x + y \le 4$; $x + 3y \ge 6$; $x, y \ge 0$.
   - SPLTV alokasi modul sensor laboratorium mekatronika SMK.
   - Program linear optimasi perakitan drone Quadcopter & Hexacopter dengan metode titik pojok (*corner points*).
   - Optimasi kendala modal manufaktur mikro-robot.
2. **Fungsi & Relasi**
   - Invers fungsi pecahan/rasional throughput saluran frekuensi $f(x) = \frac{2x - 3}{x + 1} \implies f^{-1}(3) = -6$.
   - Komposisi fungsi dua tahap filter sinyal DSP $(f \circ g)(x) = x^2 - 4x + 18$ dengan $g(x) = x - 1 \implies f(2) = 15$.
   - Karakteristik grafik fungsi kuadrat defleksi peredam roket $f(x) = 4(x^2 - 8x + 12)$.
   - Pemodelan fungsi piecewise dan linear terapan biaya komputasi awan.
3. **Barisan & Deret**
   - Bunga majemuk investasi ekspansi lab AI ($10\%$ tahunan selama 3 tahun).
   - Sifat eksponen perkalian dan pembagian energi bersih CubeSat $E = V \cdot I \cdot t$.
   - Deret aritmetika bertahap dengan overlap sambungan ($400\text{ cm}$ dan step $+395\text{ cm}$).
   - Barisan geometri uji batas kritis 128 ton sayap drone ($500 \to 1000 \to 2000 \to \dots$).
   - Akumulasi deret geometri kumulatif $S_n$.
4. **Geometri & Pengukuran**
   - Dimensi Tiga: Kerangka kubus observatorium $PQRS.TUVW$ rusuk $12\text{ cm}$, kalkulasi jarak titik sudut $V$ ke pusat dasar $O$ ($6\sqrt{6}\text{ cm}$).
   - Bangun Datar: Kesebangunan segitiga bertingkat rangka truss antena ($AB/AC = AD/AE$).
   - Optimasi lembaran pelat komposit $30\text{ cm} \times 30\text{ cm}$ dengan potongan sudut $x = 5\text{ cm}$ menghasilkan volume maksimal $2.000\text{ cm}^3$.
   - Keliling segel konduktif melingkar $d = 35\text{ cm}$ dan estimasi kebutuhan pita emas.
   - Transformasi Geometri: Dilatasi optik proyektor HUD kokpit (skala $k = 0{,}6 \times d$).
5. **Trigonometri**
   - Perbandingan trigonometri sudut tumpul Kuadran II: $\sin A = \frac{1}{a} \implies \cos A = -\frac{\sqrt{a^2 - 1}}{a}$.
   - Pemodelan klinometer dan sudut elevasi tangga/lengan robotik $60^\circ$ terhadap dinding vertikal ($h = 3\sqrt{3}\text{ m}$).
6. **Statistika & Analisis Data**
   - Analisis diagram batang fluktuasi produksi mikrosip bulanan (lonjakan terbesar pada bulan November).
   - Modus data berkelompok waktu latensi server ($M_o = 65{,}0\text{ ms}$).
   - Rekonstruksi frekuensi data hilang via modus data kelompok ($M_o = 15{,}75 \implies f_x = 6$).
   - Rata-rata gabungan data susulan 17 modul awal + 3 modul susulan dan analisis batas ekstrem.
   - Evaluasi matriks tabel persentase silang preferensi beban komputasi multi-region.
7. **Peluang & Kombinatorika**
   - Peluang kejadian majemuk alokasi rak server data center ($P = 11/15$).
   - Peluang sederhana dan peluang komplemen pengujian 10 sensor cerdas industri.
   - Peluang bersyarat tanpa pengembalian berurutan seleksi rover dan drone ($P = 4/15$).
   - Peluang bersyarat undian voucher komputasi berstatus pengembalian parsial ($P = 1/9$).
   - Kaidah pencacahan aturan pengisian tempat (*filling slots*) token unik alfanumerik $AXBYC$ ($1.404.000$ kode).

## 💻 Fitur Utama Antarmuka

* **Tampilan Satu Soal per Halaman (Single-Question View)** dengan sinkronisasi hash URL otomatis (`#/soal/:id`), memungkinkan navigasi dinamis, bookmark, dan berbagi tautan soal.
* **Quick Question Palette (Laci / Modal Nomor Soal)**:
  * Filter tab: *Semua*, *Sudah Terjawab* (Teal/Emerald), *Ragu-Ragu* (Amber/Yellow Flag), *Belum Terjawab* (Gray Outline).
  * Indikator status visual aktif (*pulse ring* & ikon penanda).
* **3 Tipe Input Soal Interaktif**:
  1. *Pilihan Ganda Tunggal (PG)*: Kartu radio interaktif dengan hover effect halus dan badge huruf.
  2. *Pilihan Ganda Kompleks (PGK MCMA)*: Multi-checkbox pilihan dengan indikator "Jawaban benar lebih dari satu".
  3. *PGK Kategori (Matrix Table)*: Tabel interaktif penilaian Benar/Salah untuk tiap butir pernyataan.
* **Dual Operating Modes**:
  * **Mode Latihan Mandiri**: Pembahasan langkah matematis sistematis accordion dapat dibuka langsung pada tiap nomor.
  * **Simulasi Ujian TKA**: Dilengkapi countdown timer 90 menit, peringatan waktu menipis, dan rekapitulasi nilai akhir.
* **Modal Evaluasi & Rekap Skor Komprehensif**:
  * Skor total (0 - 100), jumlah benar/salah/dilewati, durasi pengerjaan.
  * Grafik progress bar persentase penguasaan per modul materi.
  * Review grid interaktif: klik nomor soal mana saja untuk melompat langsung ke soal & melihat pembahasannya.
* **Buku Saku Rumus Cepat (Formula Cheatsheet Modal)**: Referensi rumus lengkap terindeks dengan fitur pencarian instan dan tab kategori materi.
* **Strict SVG Engineering**: Visualisasi vektor tajam murni, kontras tinggi, mendukung Dark Mode & Light Mode, serta garis rusuk ruang tampak/tersembunyi yang presisi.

## 🛠️ Tech Stack

* **Framework**: React 18 + TypeScript + Vite 5
* **Styling**: Tailwind CSS 3 (responsif adaptif, dark mode class-based)
* **Mathematical Typography**: KaTeX 0.16 (inline `$..$` dan display block `$$..$$` dengan kontainer anti-overflow `overflow-x-auto`)
* **Icons**: `lucide-react`
* **Bundle Optimization**: Code-splitting vendor & katex chunks via Rollup manual chunks

## 🚀 Cara Menjalankan Aplikasi

Pastikan Node.js (v18+) telah terpasang di komputer Anda.

### 1. Menjalankan Server Pengembangan (Dev Mode)
```bash
npm run dev
```
Buka browser pada alamat [http://localhost:3000](http://localhost:3000).

### 2. Membangun Berkas Produksi (Production Build)
```bash
npm run build
```

### 3. Menguji Versi Produksi (Preview)
```bash
npm run preview
```
